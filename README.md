# 🤖 ResumeAI Pro

An AI-powered ATS Resume Analyzer built using Python, NLP, Sentence Transformers, and Google's Gemini API.

## Features

- 📄 Resume PDF Parsing
- 🤖 AI Resume Review
- ⭐ ATS Score
- 📊 Resume Match Score
- 🧠 Semantic Similarity
- 🛠 Skill Extraction
- 📈 Data Visualization
- 📄 PDF Report Generation

## Tech Stack

- Python
- Streamlit
- Sentence Transformers
- Google Gemini API
- pdfplumber
- Scikit-learn
- ReportLab
